# Master AI Studio Prompt: NutriCare AI (Auth, Admin Console & High-Speed AI)

Copy and paste the following comprehensive prompt into **Google AI Studio** to generate the complete, production-ready web application with authentication, role-based admin oversight, and optimized high-speed AI analysis.

***

### Prompt to Paste into Google AI Studio:

```text
Act as an expert full-stack web developer and elite UI/UX engineer. Build a complete, fully functional, responsive single-file web application (React, Tailwind CSS, and TypeScript) for a closed-loop digital therapeutic ecosystem called "NutriCare AI".

The application must include the following advanced features and modules:

1. User & Admin Authentication Workflow:
   - Secure login and sign-up screens supporting email/password authentication.
   - Convenient "Demo User" and "Demo Admin" quick-access buttons.
   - Forgot password recovery flow with a 4-digit code verification screen.

2. Admin Management Console (Admin Role):
   - Dedicated administrative dashboard accessible via admin credentials (`admin@nutricare.ai`).
   - Ability to review all registered user profiles, biometrics, and emergency contact details.
   - Actionable controls to approve/verify pending accounts, revoke user access, or permanently remove user data.
   - System telemetry and audit logs for lab reports and meal scans across the ecosystem.

3. High-Speed AI Processing & Multimodal Analysis:
   - Integrate optimized backend calls using Gemini's flash models (`gemini-2.5-flash`) to ensure sub-second analysis speed.
   - Health screening report scanner extracting biomarkers (Glucose, Cholesterol, Triglycerides, Blood Pressure) with risk assessments.
   - AI meal glycemic scanner analyzing uploaded food photos or descriptions to calculate calories, macronutrients (Protein, Carbs, Fats), glycemic load, and sugar spike risk.

4. Biometric & Calorie Balance Engine:
   - Automatic calculation of BMR (Mifflin-St Jeor), TDEE (activity multipliers), and BMI category status.
   - Real-time daily calorie balance scorecard with over-consumption alerts.
   - Reward feature tracking streaks and therapeutic milestone badges.

5. Emergency SOS & Family Alarm:
   - Emergency SOS button triggering a visual red flashing screen, Web Audio API siren synthesis, and direct phone/SMS links to family contacts.

Technical Requirements:
- Use Tailwind CSS for a sleek dark medical theme (#07090E background, cyan and rose accents).
- Embed Lucide icons for visual telemetry.
- Maintain persistent state via localStorage or secure component state.
```

***

## How to Use This in Google AI Studio:
1. Open [Google AI Studio](https://aistudio.google.com/).
2. Start a new **Chat** or **Freeform** prompt.
3. Paste the text block above into the prompt input.
4. Set the model to `gemini-2.5-flash` and click **Run** to generate the complete application code.
